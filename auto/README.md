# الوضع التلقائي (Auto)

ملفات جديدة فقط — اليدوي (`live-relay.yml` و`server.js` و`decode.js` ولوحة `docs/index.html`) ما تغيّر.

**التشغيل:** Actions ← **Live Stream Relay (Auto)** ← Run workflow.
**اليدوي:** Actions ← Live Stream Relay (زي ما هو). لا تشغّل الاثنين مع بعض.

## وش يسوي
- عند 5 ساعات يشغّل نسخة جديدة من نفسه (حد أقصى `max_chain`، الافتراضي 4).
- الجديد ينقل الأسماء والمصادر وعمليات الفك من القديم بنفس الـid، ويفحص كل مسار، وينشر `docs/ptr/*.json` و`current-stream.json` بكوميت واحد.
- القديم يعرض النفق الجديد بترويسة `X-Zone-Next` (المشغّل ينتقل لحاله)، وما ينتهي إلا بعد: 5 دقايق على الأقل + دقيقتين بدون طلبات مشاهدة + نقل أي شيء جديد (أقصى 15 دقيقة).
- كل خطوة تجيك على تيليجرام.

## إيقاف التجديد
Settings ← Secrets and variables ← Actions ← Variables ← `ZONE_AUTO` = `off`
(لو المتغير غير موجود = مفعّل. ولو ما قدر يقرأه = يوقف للأمان.) ولو تبي إيقاف فوري: ألغِ التشغيل من Actions.

## الروابط الثابتة
`https://<حسابك>.github.io/<الريبو>/ptr/<الاسم>.json` — حطه بالأدمن مرة وحدة (خانة السيرفر).
- ممرر مسمّى (`/live`) وعمليات الفك: يتسوى لها رابط ثابت تلقائيًا بنفس اسمك (الممرر بحروف صغيرة).
- الروابط بدون اسم (`/mh` و`/relay` و`/u`): من الصفحة `docs/pointers.html`.
- الرابط اللي فيه `؟توكن` ما ينشر علنًا إلا بموافقتك الصريحة (الصفحة عامة).

## الصلاحيات
`GH_PAT` يحتاج صلاحية تشغيل الأكشن (workflow) وقراءة المتغيرات (variables read).
